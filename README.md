# 🌱 EcoCampus UNIAJC

Sistema de Gestión Inteligente de Residuos para la Universidad Antonio José Camacho

## 🎯 Descripción

EcoCampus es una plataforma web colaborativa diseñada para mejorar la gestión de residuos sólidos en el campus universitario. Permite a estudiantes y personal reportar problemas, sugerir mejoras y aprender sobre prácticas sostenibles.

## ✨ Características

- 📝 **Sistema de Reportes en Tiempo Real**
- 🗺️ **Mapa Interactivo del Campus** 
- 📊 **Dashboard de Estadísticas**
- 📚 **Centro de Aprendizaje sobre Reciclaje**
- 🌍 **Seguimiento de Impacto Ambiental**
- 🔔 **Sistema de Notificaciones**

## 🏗️ Tecnologías

- **Frontend:** HTML5, CSS3, JavaScript Vanilla
- **Backend:** Netlify Functions
- **Hosting:** Netlify
- **Almacenamiento:** JSON + localStorage
